## 📂 Featured Projects

### 🏢 [VotifAI](https://github.com/mcontrerasdevpro/VotifAI) — Multi-tenant SaaS for property management firms · **In production** · *Jul 2026 – Present*

Cloud platform that centralises the work of Spanish property management offices (*administración de fincas*) and their owners' associations: legally compliant owners' meetings, accounting, SEPA direct debits, bank reconciliation and tax forms — across the whole portfolio at once.

- **Stack:** React 19, Vite, Tailwind CSS v4 · Node.js, Express · PostgreSQL with versioned migrations · Docker on a self-hosted VPS
- **Highlights:**
  - Live voting from mobile, vote delegation and **AI transcription** of each owner's speech
  - **Tamper-evident ledger** chained with SHA-256 hashes; signed minutes with integrity fingerprint
  - Norma 43 bank statement import with **rule-learning reconciliation**; SEPA pain.008 / pain.001 files
  - Generates Spanish tax forms (111, 190, 347) · tenant isolation · role-based access · GDPR
  - **280 automated tests** (206 route tests + 74 against a real PostgreSQL)
- [🔗 Live](https://votifai.nexuraia.com) · [📁 Source](https://github.com/mcontrerasdevpro/VotifAI)

### 🎙️ Nexura — Voice & chat AI agent · **In production**

AI assistant on [nexuraia.com](https://www.nexuraia.com) that answers by voice when you speak and by text when you write.

- **Stack:** n8n workflows · self-hosted Whisper (faster-whisper) for speech-to-text · Google Gemini agent with session memory · Docker
- **Highlights:** end-to-end pipeline webhook → transcription → AI agent → response, fully self-hosted to keep costs and data under control

### 🗳️ [Civora](https://github.com/mcontrerasdevpro/civora) — Verifiable voting infrastructure with zero-knowledge identity · **Public demo**

Proof of concept for secure digital voting in Spain: it checks voter eligibility with official Spanish identity documents while keeping the vote anonymous on-chain, and lets anyone recount the results from the contract's public events.

- **Stack:** Next.js · TypeScript · Solidity smart contracts (Hardhat, Ethereum Sepolia testnet) · PostgreSQL · Zod · pnpm monorepo · Docker on a self-hosted VPS
- **Highlights:**
  - **Zero-knowledge identity** with ZKPassport: the DNIe/passport chip proves age and nationality, and the proof is **verified inside the smart contract**, not on a server
  - **Spanish digital certificate** login via Autofirma: CAdES signature validation, trust chain up to FNMT / DGP and **OCSP revocation checks**
  - One vote per person with **nullifiers**; each proof is bound to the chosen option so it can't be reused
  - Engineering documentation: **architecture decision records (ADRs), threat model and security audit**
  - Accessibility: audio reading of the ballot with a privacy warning before anything is read aloud
- [🔗 Live demo](https://civora.nexuraia.com) · [📁 Source](https://github.com/mcontrerasdevpro/civora) · AGPL-3.0
